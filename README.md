# To-Do List CLI

A simple command-line task manager built with Python.

## Features
- Add tasks
- Show all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks to a file (tasks persist after closing)

## How to run
1. Make sure Python is installed
2. Clone this repository
3. Run the file:
python todo.py

## Tech used
- Python (no frameworks, no external libraries)
